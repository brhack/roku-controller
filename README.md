# SALA — Roku Controller

Control remoto web para dispositivos Roku en tu red local.

## Uso
1. Abre el sitio en Chrome o Edge en el mismo Wi-Fi del Roku.
2. Agrega la IP del televisor (Ajustes → Red → Acerca de).
3. En el Roku: Ajustes → Sistema → Ajustes avanzados → Control por aplicaciones móviles → Permitir.
4. Acepta el permiso de red local del navegador.

Las órdenes salen del navegador al puerto 8060 del Roku (ECP).
